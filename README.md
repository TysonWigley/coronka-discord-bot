# Coronka Discord Bot

Official community bot for Coronka Arena, Coronka Duel, and Kingdoms of Coronka.

Features:
- One-command server bootstrap with `/setup`
- Self-assign player roles with `/roles`
- Separate LFG flows for all three games with room codes
- Arena ranked/casual option
- Optional temporary voice rooms
- Public feedback with up/down voting
- Official playtest announcements and RSVP buttons

Required environment variables:
- `DISCORD_TOKEN`
- `CLIENT_ID`
- `GUILD_ID`

Runtime:
- Node.js
- discord.js
- Railway
